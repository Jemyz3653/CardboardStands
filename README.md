# Cardboard Stands 1.0.0

Minecraft Java 26.3 · Java 25 · Fabric Loader 0.19.5+ · Fabric API 0.163.0+ for 26.3.

## Как пользоваться

1. Положи JAR мода и Fabric API в папку `mods`. Для одиночной игры достаточно клиента. Для мультиплеера установи оба JAR на сервер и у всех игроков.
2. Сделай картонку в сетке 2×2. В верхнем ряду две бумаги, в нижнем бумага слева и палка справа. В творческом режиме найди «Картонка» в функциональных блоках. Команда для выдачи: `/give @s cardboardstands:stand`.
3. Нажми на верхнюю грань твёрдого блока, чтобы поставить картонку на ножку. Нажми на боковую грань, чтобы повесить её вплотную к стене.
4. Нажми ПКМ пустой рукой. Перетащи один PNG в окно или вставь путь к файлу и нажми «Загрузить PNG». После загрузки картинка появится в предпросмотре и в мире. Для замены загрузи другой файл. Кнопка «Убрать картинку» очистит картонку.
5. В редакторе введи угол от 0 до 360° с точностью 0,1° и нажми «Применить угол». Для напольной картонки 0° — север, 90° — восток. Для настенной 0° — верх картинки направлен вверх, положительные углы поворачивают её по часовой стрелке.
6. Shift + ПКМ пустой рукой добавляет 90° к текущему углу. Настенная картонка слегка уменьшается у диагональных углов, чтобы углы рамки помещались в одном блоке.

## Файлы и сервер

- Максимум 8192×8192 пикселей и 64 МиБ на файл. Поддерживаются прозрачность и любые пропорции в пределах этих размеров. На GPU с меньшим лимитом текстура уменьшится только на клиенте.
- Загруженный PNG хранится в папке `cardboardstands` внутри каталога мира. При переносе мира сохрани эту папку вместе с остальными данными мира.
- Картинку видят игроки с модом. Менять её может игрок, поставивший картонку, или оператор сервера. При разрушении постройки выпадает пустая картонка.
- Ввод пути и перетаскивание работают с файлами на компьютере игрока. Изображения отправляются на игровой сервер небольшими частями.

## Build from source

Use JDK 25 and run `./gradlew build` on Linux/macOS or `gradlew.bat build` on Windows. The release JAR is in `build/libs`. Run `./gradlew runClientGameTest` to exercise 8K upload, rendering, and image removal with the real client. The model, textures, and pixel icon can be regenerated with `python tools/generate_assets.py` using Pillow.
